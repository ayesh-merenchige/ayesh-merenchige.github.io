STUDY-01

Weight-Lifting Posture Evaluator (LSTM + MediaPipe)

Analyzing motion over time instead of just static poses.

94% ACC — Bicep Curls 96% ACC — Tricep Kickbacks
  • Tracks body movement across frames with Google MediaPipe; the LSTM network reads the motion sequence, so bad form is caught far better than from a single frame.
  • Extracts frame metrics such as joint angles, torso tilt and head position to understand the full movement pattern.
  • A lightweight Flask web app delivers live, frame-by-frame tips on common mistakes (flared elbows, twisting torso, misaligned wrists).
  • Impact: a camera-only solution helping home fitness users fix technique without expensive sensors.
Python · TensorFlow · Keras · NumPy · Pandas · Matplotlib · MediaPipe · Flask
STUDY-02

Lightweight Cashew Nut Grader (Optimized YOLOv8 + Raspberry Pi 4B)

Making a super-accurate model tiny enough to run on cheap hardware.

97.21% CLASSIFICATION ACC 0.949 MAP 30 FPS ON PI 4B
  • Built and labeled the first cashew nut image dataset from Northern Province, Sri Lanka — whole, half-split, broken and diseased nuts.
